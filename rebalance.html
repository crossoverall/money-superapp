📖 วิธีทำงานและคำแนะนำ (Guide & Tips)
วิธีทำงาน — งบรวมถูกแบ่งตามสัดส่วน Core/Ballast/Satellite ก่อน จากนั้นในแต่ละกลุ่ม ระบบจะเติมเงินให้สินทรัพย์ที่ "ตามหลัง" สัดส่วนเป้าหมายมากที่สุดก่อน ถ้าตัวไหนมูลค่าเกินเป้าหมายอยู่แล้วจะไม่เติมเดือนนี้ (ค่า = 0) แล้วนำงบไปให้ตัวที่ตามหลังแทน — ไม่มีการขายสินทรัพย์ใดๆ ทั้งสิ้น

ใช้ทุกเดือนยังไง — ก่อนซื้อแต่ละเดือน อัปเดต "มูลค่าปัจจุบัน" ของทุกตัวตามราคาจริง แล้วดูผลลัพธ์ใหม่

เคล็ดลับ — ในช่อง "มูลค่าปัจจุบัน" หรืองบรวม พิมพ์ +10000 หรือ -5000 แล้วกด Enter/คลิกออกนอกช่อง เพื่อบวก/ลบจากค่าเดิมโดยไม่ต้องคำนวณเอง

ตั้งค่า API ดึงราคาหุ้น / ETF

• Crypto (BTC, ETH ฯลฯ): ไม่ต้องใช้ API key — ดึงผ่าน Coinbase API ฟรีทันที (USD $)
• ทองคำแท่งไทย (GOLD, GOLDBAR): ดึงราคาขายออกสมาคมค้าทองคำสดฟรีอัตโนมัติ (THB ฿)
• YLG-GOLD (กองทุน YLG Gold Fund): ระบุ NAV ต่อหน่วย (฿) โดยตรง เนื่องจากราคากองทุน ≠ ราคาทองคำแท่ง
• อัตราแลกเปลี่ยน USD/THB: ดึงสดจาก Open Exchange Rates อัตโนมัติ
• หุ้นและ ETF สหรัฐฯ (NVDA, SGOV) และหุ้นไทย SET (GULF, PTT): ใส่ API Key ฟรีจาก Twelve Data หรือ Finnhub เพื่อดึงราคาอัตโนมัติ
• กองทุนรวมไทย (K-WORLDX, SCBCE ฯลฯ): กองทุนเปิดของ บลจ. ไม่มี API สดสาธารณะบนเบราว์เซอร์ ผู้ใช้สามารถระบุราคา NAV ต่อหน่วย (฿) และจำนวนหน่วยได้โดยตรง ระบบจะจำราคาไว้และคำนวณสัดส่วน DCA ให้อัตโนมัติ
