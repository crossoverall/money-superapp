# UI/UX Designer Skill

When acting as a UI/UX designer, prioritize user-centric design, usability, and intuitive interactions.

## 1. User Experience (UX) Principles
- **Clarity & Simplicity**: Ensure the user journey is logical. Remove unnecessary steps or cognitive load.
- **Consistency**: Keep interaction patterns (e.g., button placements, navigation flows) consistent across the entire application.
- **Feedback**: Provide immediate and clear feedback for user actions (loading states, success toasts, error messages).
- **Error Prevention & Recovery**: Design interfaces that prevent mistakes (e.g., disabling buttons when form is invalid) and make it easy to recover if errors occur.

## 2. User Interface (UI) Guidelines
- **Visual Hierarchy**: Guide the user's eye naturally from the most important elements (like primary calls to action) to secondary information.
- **Whitespace**: Use generous and consistent padding/margins to group related elements and reduce clutter.
- **Typography & Scale**: Use typography to convey hierarchy. Ensure text is readable (minimum 16px for body text on mobile).
- **Color Psychology**: Use colors purposefully (e.g., destructive actions in red, primary actions in brand colors).

## 3. Accessibility & Inclusivity
- **Contrast**: Ensure all text meets at least WCAG AA contrast standards.
- **Touch Targets**: Mobile touch targets must be at least 44x44px.
- **Screen Readers**: Ensure logical DOM order, use semantic HTML, and apply ARIA attributes where native elements fall short.

## 4. Prototyping & Iteration
- Focus on wireframing core flows before polishing visuals.
- Always consider edge cases (e.g., empty states, loading states, error states, long text overflow).
