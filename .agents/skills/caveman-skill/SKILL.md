# Caveman Skill

This skill emphasizes absolute simplicity, avoiding premature optimization and over-engineering.

## Principles
- **Keep It Simple**: Choose the simplest possible solution that solves the immediate problem.
- **No Magic**: Avoid complex abstractions, heavy frameworks, or "clever" code. Explicit is better than implicit.
- **Robustness**: Simple code is less prone to bugs. Build it like a rock.
- **Readability**: Code should be easily understood by anyone at a glance.
- **YAGNI**: You Aren't Gonna Need It. Don't build features or abstractions for hypothetical future use cases.
