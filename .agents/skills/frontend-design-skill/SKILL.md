# Frontend Design Skill

This skill enforces high-quality visual design principles for the frontend.

## 1. Typography
- Use clear, legible fonts with a logical hierarchy.
- Maintain appropriate line heights (usually 1.4 - 1.6 for body text) and spacing.

## 2. Color & Contrast
- Stick to the project's color palette.
- Ensure high contrast for text (WCAG AA or AAA standards).
- Use color to convey meaning (e.g., red for errors, green for success) but do not rely on color alone.

## 3. Layout & Spacing
- Use a consistent spacing scale (e.g., multiples of 4px or 8px).
- Balance whitespace to give UI elements room to breathe.
- Group related items visually using proximity and borders/backgrounds.

## 4. Visual Feedback
- Provide clear visual cues for interactive elements (hover, focus, active states).
- Use subtle animations or transitions to smooth state changes.
